# Groq Whisper Voice to Text — exteraGram Plugin

Плагин для клиента **exteraGram**, который перехватывает записываемые голосовые сообщения (ГС), отправляет аудио в **Groq Whisper API** и отправляет распознанный текст в чат вместо аудиозаписи. Если голосовое сообщение записывалось в ответ на чьё-то сообщение, распознанный текст отправляется реплаем на то же сообщение.

---

## Возможности

- **Перехват ГС на лету**: при записи и отправке голосового сообщения отправка аудио отменяется, а аудиофайл обрабатывается нейросетью.
- **Сохранение ответов (Reply)**: если вы отвечали на сообщение собеседника, текст придёт ответом именно на это сообщение. Если ответ не выбирался — сообщение отправится обычным текстом в чат.
- **Никаких сложных систем и утечек соединений**: используется одно прямое HTTPS-соединение (`http.client.HTTPSConnection` с заголовком `Connection: close`), которое открывается исключительно на время отправки запроса и закрывается сразу по завершении.
- **Чистый JSON без лишних данных**: на Groq передаётся `response_format="json"`, возвращающий чистый текст без таймкодов и служебных сегментов.
- **Фоновая обработка**: сетевой запрос выполняется в очереди фоновых задач (`PLUGINS_QUEUE`), не блокируя интерфейс приложения (UI Thread) и не вызывая зависаний.
- **Поддержка мультиаккаунта**: сообщение отправляется именно с того аккаунта, на котором записывалось голосовое сообщение.
- **Уведомления в интерфейсе**: при ошибках сети или неверном ключе выводится всплывающее сообщение (Bulletin) Telegram.

## Настройки на стороне клиента

В настройках плагина (`exteraGram Настройки` > `Плагины` > `Groq Voice to Text`) доступны:

1. **Включить замену ГС на текст (Switch)**:
   - Переключатель вкл/выкл. При выключении голосовые сообщения отправляются стандартно без перехвата.
2. **Groq API Key (Input)**:
   - Поле для ввода вашего API-ключа Groq (`gsk_...`).
   - Если ключ не указан, голосовое сообщение не блокируется, а плагин показывает предупреждение.
3. **Модель Whisper (Input)**:
   - Выбор модели транскрибации.
   - По умолчанию: `whisper-large-v3-turbo` (быстрая и точная).
   - Можно указать: `whisper-large-v3` или любую другую модель Whisper, поддерживаемую Groq.

## Как получить API-ключ Groq

1. Перейдите в [Groq Console](https://console.groq.com/).
2. Зарегистрируйтесь или войдите в аккаунт.
3. Откройте раздел **API Keys** (`https://console.groq.com/keys`).
4. Нажмите **Create API Key**, скопируйте полученный ключ (`gsk_...`).
5. Вставьте ключ в настройках плагина в exteraGram.

*(У Groq есть бесплатный тариф с высокой скоростью работы Whisper).*

## Установка в exteraGram

### Способ 1: Добавление репозитория в Каталог (рекомендуемый)
1. В exteraGram перейдите в **Настройки -> Плагины -> Каталог плагинов**.
2. Нажмите **+ Добавить репозиторий -> Git-репозиторий**.
3. Вставьте ссылку на репозиторий:
   `https://github.com/Quenby03/exteragram-voice-to-text`
   *(Или откройте прямую ссылку: [Добавить в exteraGram](https://t.me/exteraPluginRepo?git=https%3A%2F%2Fgithub.com%2FQuenby03%2Fexteragram-voice-to-text))*
4. Нажмите **Установить** на карточке плагина.

### Способ 2: Отправка файла в Telegram
1. Отправьте файл `groq_voice_to_text.py` в Telegram (например, в «Избранное» / Saved Messages).
2. Нажмите на файл в чате.
3. exteraGram предложит установить плагин — подтвердите установку и включите его.
4. Зайдите в настройки плагина и укажите ваш `Groq API Key`.

### Способ 3: Копирование на устройство
Поместите файл плагина в директорию плагинов приложения:
```
/data/user/0/com.exteragram.messenger/files/plugins/groq_voice_to_text.py
```
После чего включите плагин в меню `exteraGram Настройки` > `Плагины`.

## Системные требования

- **exteraGram**: `>= 12.5.1`
- **Plugin SDK**: `>= 1.4.4.3`
- **Python**: `3.11` (встроен в exteraGram Chaquopy)
- Дополнительные библиотеки `pip` не требуются (используются встроенные модули Python `http.client`, `ssl`, `json`, `uuid`).
