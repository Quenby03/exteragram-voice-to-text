# Face Privacy — Кружки

Локальный плагин exteraGram для маскировки лиц в исходящих видеокружках. Плагин использует ONNX-экспорт `yolov11n-face.onnx` из проекта `face-clear-tg`, Java runtime на базе ONNX Runtime Android и Android `MediaCodec`. Клиент пересобирать не нужно.

## Что делает

- Перехватывает отправку видеокружка, запускает YOLO по умолчанию на каждом втором кадре и повторно отправляет тот же объект сообщения с обработанным файлом.
- Связывает рамки между проверками, прогнозирует движение лица и удерживает маску заданное число кадров (по умолчанию 15). Если YOLO пропускает лицо, дополнительно пробует системный Android FaceDetector.
- Поддерживает пикселизацию, размытие и сплошную цветную маску. Блок 5×5 усредняет каждый участок в один цвет, оставляя примерно 4% пространственных отсчётов внутри маски.
- Сохраняет размер кадра, временные метки и исходную аудиодорожку. Видео перекодируется в H.264, поэтому оно не будет побитово идентичным исходнику; качество перекодирования задаётся битрейтом.
- При невозможности обработать распознанный кружок блокирует его отправку, а не отправляет необработанный файл.

## Настройки

Можно менять режим маски, шаг детекции, порог уверенности, NMS, отступ рамки, время удержания, размер блока пикселизации, радиус размытия, цвет маски, битрейт, NNAPI, число CPU-потоков и резервный системный детектор.

## Установка и первый запуск

Добавь репозиторий Maduro в каталог exteraGram и установи **Face Privacy — Кружки**. При первой попытке отправить кружок плагин загружает по HTTPS из каталога assets этого репозитория модель и arm64 runtime-файлы (около 43 MiB), сверяет SHA-256 и сохраняет их во внутреннем каталоге приложения. После этого кадры и модель обрабатываются только локально; видео на сервер загрузки не отправляется.

Пакет собран для Android `arm64-v8a`, включая Pixel 9 Pro. Для моделей/ABI вне этого целевого устройства плагин отменит отправку с сообщением об ошибке. Плагин требует exteraGram `12.5.1+` и Plugin SDK `1.4.4.3+`.

## Состав

- `face_privacy_round_video.plugin` — Python-плагин для Chaquopy/Java interop.
- `src/FacePrivacyRuntime.java` — исходник видеопроцессора и YOLO-декодера.
- `assets/` — ONNX-модель, DEX-JAR и arm64-библиотеки.
- `build_index.py` — индексатор, который сканирует все `.plugin` в `plugins/` и сохраняет остальные плагины в каталоге.
- `THIRD-PARTY-NOTICES.txt` — лицензия ONNX Runtime.

Перед публикацией активы нужно разместить по пути `plugins/face_privacy_round_video/assets/` в ветке `main`. Сам плагин загружает эти файлы из raw URL репозитория только один раз и только при отсутствии локальной копии с ожидаемым SHA-256.

## Ограничения

Точность детектора не может гарантировать отсутствие всех пропусков. Трекинг и системный fallback закрывают короткие пропуски, но экстремальное размытие движения, перекрытие лица или резкий выход из кадра всё ещё могут дать неточную рамку. Проверь результат на тестовом кружке, прежде чем полагаться на настройки маски.

Работа с реальным устройством Pixel 9 Pro здесь не проверялась; подтверждена сборка Java/DEX и статическая упаковка артефактов. На устройствах, где видеоэнкодер не принимает гибкий YUV-ввод или NNAPI недоступен, NNAPI переключится на CPU, а невозможность перекодирования остановит отправку.
